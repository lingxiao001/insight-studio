# 用户指南

## 账号与第一份分析

注册普通账号后自动登录。普通账号各有 1 USD 终身模型额度；服务未配置模型时仍可使用统计分析。管理员由部署者创建，负责共享模型配置。

“运行示例”使用明确标注的合成零售数据，不调用模型。保存报告可直接打开，打开历史不会重新分析或扣费。公开文档中的 Kaggle 案例使用真实历史数据，来源见[案例说明](real-data-provenance.md)。

## 上传

选择 CSV、TSV、XLSX 或 ZIP。ZIP 会列出可选表格，选定一个成员再开始；XLSX 读取第一个工作表。单文件最多 50 MiB、80 列。超过 100,000 行时只分析文件顺序中的前 100,000 行，界面说明范围与总量未知。

可填写分析目标和关注字段，例如“比较各渠道订单金额的中位数与缺失情况”。关注字段提高相关图表和证据优先级，不会自动训练预测模型。

提交前确认模型开关。配置可用、用量读取成功且未锁定时，界面允许启用模型；新分析界面可能默认选中，提交前可取消。关闭后执行免费统计流程。模型只接收汇总，但列名、目标和小组统计仍可能包含敏感信息。

## 阅读看板

概览显示分析行列、缺失、重复和启发式质量分。探索页分七个专题，可以组合字段和类型筛选，每页最多六张图。专题表格给出分母、分位数、相关样本量、组支持数、日期粒度及遗漏范围；不能只读图形外观。

字段画像覆盖全部读取列。图表深入探索有字段数量上限、类别显示上限和最多 60 图的限制；覆盖说明会列出未选择和不适用项。某类数据没有日期或两个数值字段时，对应专题可以不适用。

Agent 页面呈现六步及模型状态。`statistical` 表示最终采用统计解释；`llm` 表示采用了模型新增文字，不代表其每句话已获验证。模型失败或未采用时查看 notes，统计结果仍可使用；已发生推理可能产生费用。

## 核对解释

- 先核对单位、分母、缺失与分析范围，再看差异大小。
- IQR 是 Q3−Q1；Q1 到 Q3 是区间。潜在异常点不自动等于错误记录。
- Pearson/Spearman 的有效样本量按变量对计算，不等于整表行数；系统未进行统计显著性或因果检验。
- 分组仅展示支持数达到条件的部分组。日期分桶也可能只是快照的条件比较，不能据此补出历史事件。
- 模型可能误读排名、方向、阈值或业务概念。高风险文字检查不能替代人工核对。

## 导出与重新分析

下载 Markdown 便于编辑，独立 HTML 内嵌图表运行库，可离线查看。HTML 延迟绘图，并提供准备全部图表用于打印的操作。报告包含预览和本地类别标签，分享前应检查敏感内容。

旧报告仍可读取。升级或失败重试会创建新任务，界面弹窗默认关闭模型；确认免费统计后发送明确 `use_llm:false`。主动启用模型才可能新增推理费用。不要为了查看保存报告点击重新分析。

删除报告不退回模型费用。只清理不再被其他分析引用的源文件。当前不支持自助密码找回；账号问题需联系本实例部署者。
