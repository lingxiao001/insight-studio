# 面向非研发读者的结论与解释

上传后，先选择关注指标，或使用识别出的常见问题。指标从表头读取，不需要手输列名。字段识别只在本地运行，不创建分析任务、不调用模型。

结果默认打开“结论与解释”：先回应用户点名的比较，再呈现补充发现。每项回答说明观察到了什么、怎样理解、不能据此判断什么，以及下一步如何核对；数字和图表按需展开。Markdown与离线HTML使用同一份结果，旧报告继续显示原概览。

## 解释规则

- 自动关注问题中明确提及的字段；毕业生表识别GPA排名、就业能力自评，通用表识别销售额、利润等。用户可换选。不能识别时描述类别构成，不编造结果变量。英文列名按词边界匹配，避免把短列名误认成其他单词的一部分。
- 关注指标需为非编号的数值列，至少5个有效值且包含不同取值；常量和记录过少的列不能从下拉框选择。通过接口明确指定的指标若不能分析，会保留所选口径并解释原因，不悄悄换成另一列。
- 目标关系扫描全部合格数值列，不受十个图表字段上限限制。每对在完整记录内计算Spearman排序相关。展示关系至少20对值、相关绝对值至少0.20；0.40／0.70为中等／较强的描述口径。这些门槛不表示统计显著或因果。
- 问题中提到的字段按出现顺序逐项回答，最多12项。即使关联很弱、成对记录不够或字段不可比较，也会保留回答，不用另一项强关联替代原问题。超出12项时，覆盖信息与范围说明会指出未回答的数量，应拆分问题继续分析。
- 图表的十列选择优先覆盖问题中的字段，再参考目标关联程度；仍最多60图。补充发现最多五项，与逐项回答分开呈现。
- 分组解释最多一项，每个保留组至少20个有效值、最多8类；展示观察差异达到目标标准差0.20的候选，交代遗漏小组。属于探索筛选，未控制混杂、未做显著性检验。
- 与量表相关的排序关系绝对值达到0.95时，提示信息高度重合、需核对采集和评分来源；不直接背书量表有效，也不据此断言造假。
- 支持不足时明确说明，保留可核对的分布或类别事实，不为填满卡片制造结论。
- 问题提及的非排名数值字段可生成一项交叉观察：至少40对有效值、两列至少4个不同值；在配对样本中按解释字段Q3、目标Q1划分，包含等于边界的值。高值组至少10条、交叉组至少5条时才展示，分母为该高值组，不是全表。这是样本分位划分，不是合格标准。

逐项回答的状态是描述规则，不是置信度、显著性或教学效果评级：

| 状态 | 页面含义 | 判定口径 |
| --- | --- | --- |
| `supported` | 观察到共同变化 | 至少20对有效值，排序相关绝对值不低于0.20 |
| `partial` | 未见清晰单调关系；或标为“当前方法不适用” | 数值比较中至少20对有效值，但排序相关绝对值低于0.20；类别比较未采用数值排序方法时另给明确标签 |
| `insufficient` | 暂不足以判断 | 成对记录不足，或当前字段不能形成可比较的数值排序关系 |

逐项关系回答当前侧重数值排序。类别、文本或疑似编号不能强行计算Spearman；类别字段的回答标为“当前方法不适用”，明确本项未做类别间差异比较，不将其写成关联弱或样本不足。类别与数值指标可另看分组统计，其解释仍需交代样本组成与混杂因素。数值弱关联也不能据此说“完全无关”。

`brief.coverage`记录扫描字段、计算关系、分析行数，以及点名问题的识别、回答和遗漏数量。首页和导出使用同一份brief，不在浏览器重新计算。可选模型接收有界聚合证据和逐项回答状态，原始行和类别标签不外传；规则结论不会被模型返回替换。模型文字审查会拦截部分已知的“就业能力自评变成真实就业率、录用或薪资”的肯定断言，不能据此认为所有教育语义和数字已被验证。

## Graduation案例

![公开分析示例目录](screenshots/12-public-examples.jpg)

网站内置两个免登录的公开分析示例：`/?view=examples`为目录，`/?example=graduation-employability`和`/?example=graduation-academic`分别阅读就业能力与学业排名。登录页、研究室和侧栏均提供入口。示例与私有任务分开，只读浏览与下载不创建任务、不调用模型、不消耗额度。

仓库中的`backend/app/example_data/`仅保留聚合快照：结论、分箱计数、排序关联与交叉组计数。不附学生编号、逐行数据、原始散点或私有任务标识。公开HTML和Markdown也由同一快照导出。数据来源、CC BY 4.0和预处理说明随页面与报告保留；它们不改变程序的AGPL许可。

来源：Wang, Dongxuan (2025), *Graduation*, Mendeley Data, V1，[10.17632/c8ypkyswv3.1](https://data.mendeley.com/datasets/c8ypkyswv3/1)，CC BY 4.0。来源描述为河北农业大学2020届计算机专业253名毕业生的课程与量表记录；这不是独立的真实性审计。

案例使用预处理CSV：原始86列中，五期就业指导取等权均值、七期形势与政策取等权均值，12列变2列，结果253行、76列；表头转snake_case，未删除学生、填补或标准化分数。任一期缺失时，该组均值也保留缺失。原始86列工作簿超过产品80列限制且有两行表头，不能直接当作预处理文件。

从上述Mendeley固定V1下载原始`Data.xlsx`。`prepare-graduation.py`先核对SHA-256，再读取`Various Scores`工作表的第二行字段名，规范列名、将`Name`列改名为`student_id`，并进行上述两组课程合并。原始工作簿SHA-256为：

```text
e131105640e0a4c43064897e1d5871844b9b4ff98698831687ace8ff85453450
```

```bash
PYTHONPATH=backend .venv/bin/python scripts/prepare-graduation.py \
  --input /path/to/Data.xlsx \
  --output .local/graduation/Graduation_clean.csv
```

脚本只处理这一固定版本，结构或校验和不一致时停止，不猜测其他文件的表头。原始工作簿、预处理CSV和包含个人记录的报告应保存在忽略目录，不提交到仓库。

```bash
PYTHONPATH=backend .venv/bin/python scripts/graduation-case.py \
  --input .local/graduation/Graduation_clean.csv \
  --output-dir .local/graduation/reports
```

脚本生成学业、就业能力两个独立报告，不调用模型、不将数据写入仓库。也可在界面上传同一CSV，选择自动识别的问题。

维护者可从相同预处理文件重建公开聚合快照（会更新仓库内的两个示例JSON）：

```bash
PYTHONPATH=backend .venv/bin/python scripts/build-graduation-examples.py \
  --input .local/graduation/Graduation_clean.csv
```

公开API只有固定示例目录、详情及报告的GET请求免登录；其他账号数据、上传、任务和模型接口仍要求登录。示例内容随应用代码部署，不依赖本地数据目录或某个演示账号。

- `gpa_rank`是名次，越小越靠前，不是GPA数值；课程可能参与排名计算，关联不能视为独立影响。
- `employment_ability_scale`是自评，不是实际就业状态、就业率、薪资或录用。
- `internship`是实习成绩，不是次数、时长或有无实习。
- 四／六级0/1指标没有编码字典时保留原编码，不自动称为通过率。
- 量表与排名的排序高度对应是值得核对的测量现象，不能解释为能力的因果作用。

这份案例有两组可具体核对的观察：

- 就业能力自评与实习成绩的排序相关为0.3005，与主动学习能力自评为0.7644，均使用253条成对记录。实习成绩不低于92的76条记录中，有10条就业能力自评不高于78，占13.2%。这说明两项记录并不能互相替代；它不能证明延长实习或加强某门课程会改善就业结果。
- 学业案例中，一个量表与GPA排名的排序相关为−0.9799。应先核对是否独立采集、是否共享计分来源；其绝对值很高，不能成为量表有效、课程独立影响或数据造假的证明。课程成绩与排名之间的关系也可能部分来自排名计算本身。

以上数字用于解释这份公开样本，不能外推为其他年级、专业或高校的规律。公开快照与新上传任务分别保存；历史快照缺少新增逐项回答字段时仍可阅读，不会因打开页面而重新运行分析。
