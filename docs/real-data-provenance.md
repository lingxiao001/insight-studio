# 真实案例：纽约 Airbnb 2019 快照

本案例使用公开历史观察数据，演示单表 EDA 的读取、质量检查、图表和解释边界。代码仓库不附原始 CSV、私人报告或付费调用流水；复现脚本按需从官方 Kaggle 固定版本下载并核验哈希。

发布者将来源归于 Inside Airbnb。其[数据说明](https://insideairbnb.com/data-assumptions/)说明数据来自公开 Airbnb 页面及日历、评论，是特定时间的挂牌快照；因此按真实观察数据使用，而不是合成样本。本项目无法逐条验证每个历史页面。

Kaggle version 3 的更新时间是发布记录，不是精确采集日。文件没有 `last_scraped` 字段；`last_review` 是各挂牌的最后评论日期，最大值 2019-07-08 也不能当作快照采集日期。这里称“2019 历史快照”，不虚构某一天的抓取时间。

## 字段与可复算摘要

16 列包括挂牌与房东标识、标题、行政区与社区、经纬度、房型、挂牌价、最短入住、评论数量及日期、每月评论、该房东在本数据中的挂牌数、未来 365 天可订天数。公开说明只使用聚合，不重印姓名、房东标识或逐行位置。

全文件 `price` 有效 n 为 48,895：均值约 152.72，中位数 106，Q1=69、Q3=175，IQR 宽度为 106；P95=355，范围 0–10,000。零值 11 条，不能直接解释为免费成交。按 1.5×IQR 规则标记的潜在异常值为 2,972 条；P95 不是该异常阈值。

`last_review` 有效 38,843 行、缺失 10,052 行。按最后评论日分桶时分母与全表不同，不能把缺失当成零评论或零订单。具体数量可用 `scripts/real-kaggle-case.py --submit` 在自己实例免费重算。

本案例通常生成 49 张图，包含七专题与三类挂牌价格分组：行政区、社区、房型。社区有 221 个不同值，符合类别候选规则；图表展示数量仍有 Top 类别和支持数限制。图数由统计选择规则产生，不代表枚举全部关系。

## 必须保留的解释边界

| 字段或图形 | 可以说 | 不能直接说 |
| --- | --- | --- |
| `price` | 当前快照中的每晚挂牌价格 | 成交价、营收、利润或支付金额 |
| `availability_365` | 未来日历显示可订的天数 | 空置率、入住率；不可订也可能是房东屏蔽 |
| `last_review` | 每个挂牌在快照中的最后评论日 | 订单事件序列、当日新评论数、历史价格轨迹 |
| 评论统计 | 已观测评论及相关缺失 | 精确订单数或需求总量 |
| 经度/纬度与价格 | 所选记录中的描述性相关 | 空间因果、区域政策效果或未经分析的方向规律 |
| 分组中位数 | 支持数足够且选中的组之间的条件比较 | 所有社区排名、统计显著差异或关键驱动因素 |

源位置经过平台扰动，不适合还原精确地址；挂牌快照也不是当前市场。更多字段解释可参考 Inside Airbnb 的[当前数据字典](https://docs.google.com/spreadsheets/d/1iWCNJcSutYqpULSQHlNyGInUvHg2BoUGoNRIGa6Szc4/edit?usp=sharing)，但当前字典版本不能替代这份历史 CSV 的字段核对。

## 截图与模型文字

公开截图来自新的本地演示实例，真实数据统计在本地重算；Agent 中的模型文字由已有输出离线重放，并保留复核说明。这不是新付费推理、真实公开账单或持续在线 demo。公开摘要只保留能复算的统计，不复制私人模型流水与完整历史报告。

模型可能把 Q1–Q3 区间误称为 IQR，或误判组样本量、方向与显著性；展示解释时应以本页正确口径和统计表为准。检查器不是完整事实验证，使用模型前后都需要业务复核。
