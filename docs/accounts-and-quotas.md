# 账号、数据归属与额度

每个用户使用独立账号。注册后自动登录，角色固定为普通用户；客户端不能指定管理员角色或修改额度。初始管理员由服务端环境配置创建。

## 注册与登录

用户名经 NFKC 规范化，长度 3–32 个字符，允许字母、汉字、数字、下划线、点和短横线，首字符不能为点或短横线；唯一性比较对 ASCII 字母不区分大小写。密码长度 10–128 个字符，服务端用带随机盐的 PBKDF2-HMAC-SHA256 保存，迭代次数 600,000。

登录错误统一显示用户名或密码不正确。按来源地址限制登录尝试（5 次/5 分钟）及注册尝试（5 次/15 分钟），成功请求也计入窗口。会话 Cookie 有效期七天，签名绑定用户 ID 和会话版本，使用 HttpOnly、SameSite=Strict；HTTPS 部署需启用 Secure。

`ADMIN_USERNAME` 和 `ADMIN_PASSWORD` 用于首次创建管理员。数据库已有管理员时不会覆盖密码或角色，环境变量不是密码重置接口。旧 `APP_PASSWORD` 不再支持共享密码登录。

## 权限与数据

| 能力 | 普通用户 | 管理员 |
| --- | --- | --- |
| 上传、创建与读取自己的分析 | 支持 | 支持 |
| 下载、重试、删除自己的报告 | 支持 | 支持 |
| 访问其他账号报告 | 不支持 | 普通报告接口不支持 |
| 查看自己的模型用量 | 支持 | 支持 |
| 配置共享后端模型密钥 | 不支持 | 支持 |
| 应用累计模型额度 | 每账号终身 1 USD | 无累计金额上限 |

跨账号上传、任务和报告 ID 返回 404。退出或切换账号时前端清理工作区，后端每次仍核验拥有者。任务排队后仍按任务拥有者计费，不随浏览器后来登录的账号变化。

## 费用口径

普通用户的可用余额为：

```text
max(0, 1 USD - 已结算费用 - 进行中预留 - 待核实费用)
```

预留覆盖完整请求的最坏费用，因此可用余额大于零也可能不足以下一次调用。统计分析不使用模型额度。管理员的 `unlimited=true`，`limit_usd` 与 `remaining_usd` 均为 `null`；这不代表免费，也不取消价格、供应商余额、单次输出或异常账单保护。

额度跨所有密钥周期累计。重启、重新部署、删除任务和管理员更换密钥都不会恢复普通账号额度。一个用户耗尽不会锁住其他用户。用量接口按当前用户统计，不公开其他账号流水。

## 自托管时的限制

这里的 1 USD 是本应用的账号级支出上限，不是发放的 OpenRouter 账户余额，也不会修改提供商后台限额。当前注册不验证邮箱或自然人身份，也没有自助密码找回；同一人可能注册多个账号。准备对外开放注册时，运营者需要据实际需求增加身份核验、邀请或注册审批，不能把地址限流当作唯一身份保证。

密钥只在后端保存，普通用户无需也不能读取它。详见[模型与计费](model-and-budget.md)以及[安全指南](security-guide.md)。
