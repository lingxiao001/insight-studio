# 纸面视觉与交互

界面采用纸白底、灰褐文字、细边框和低饱和强调色，让统计量、图表和来源说明成为主要内容。视觉参考日常纸质资料的秩序感，不使用第三方品牌标识，也不表示与任何品牌存在合作。

## 阅读层次

首页说明上传后的过程，以真实文件和已有报告作为入口。工作区先展示文件与分析范围，再是摘要、专题内容和可核对证据。正文避免过多色块，表格使用稳定数字对齐；图表沿用相同纸面背景、轴线、图例和提示样式。

色彩不单独承担状态含义。完成、错误、模型未采用和费用待核实均有文字说明。费用页区分上限、已结算、预留和待核实，管理员无上限用文字表达，不把 null 显示为零。

## 响应式与图表

桌面保留导航和内容的清晰关系；窄屏导航收起，表格在自身区域滚动，不扩大整页宽度。图表按页挂载，最多六张，避免几十个 Plotly 实例同时影响阅读与性能。字段与类型筛选可组合，专题之间可复用图表引用。

图表标题写出字段及统计口径。缺失率从零开始并注明百分比，分组保留支持数，时间空桶不补零。缩略标签只用于显示，底层字段身份不合并；图表和表格需要共同阅读。

## 键盘与状态

弹窗有焦点约束、Escape、恢复焦点与背景 inert。上传/授权在途禁用相关设置和关闭，避免重复提交。标签页支持方向键与 Home/End，切换专题会聚焦内容标题。减少动态效果设置关闭非必要动画，状态更新使用适度的可访问提示。

表单有可关联标签；文件选择通过明确的按钮和输入关系实现。错误信息留在相关流程中，不将身份或密钥错误暴露为调试堆栈。不同账号切换时清理旧工作区，不用视觉隐藏替代权限控制。
