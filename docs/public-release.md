# 公开发布与脱敏记录

本公开版本从代码快照重新建立 Git 历史，使用项目贡献者身份提交。私人仓库及其提交、运维记录和持久数据不随此版本发布。

## 发布范围

- 应用源码、测试、依赖锁、通用部署模板及 Markdown 文档。
- AGPL-3.0-only 完整协议与第三方依赖、数据来源说明；容器与原生发行包保留许可文档。
- 十张本地实际运行截图：登录、注册、导入入口、真实 Kaggle 统计与图表、字段画像、Agent 报告、两类账号额度和手机布局。

服务器连接目标及域名由部署者显式配置。密钥、初始密码和会话密钥均由部署者自行提供或在首次部署时随机生成；仓库没有可使用的共享凭据。

## 排除与检查

已排除 API 密钥、会话密钥、密码、账号数据库、费用账本、备份、上传原件、原始报告缓存、私人基础设施信息、个人路径和私人 Git 历史。忽略规则覆盖环境配置、运行数据、凭据文件、缓存与日志。

发布前对待上传文件进行真实凭据精确比对、已知私人标识符比对及 Gitleaks 8.30.1 检查，未发现残留。人工复核提交身份、文档和截图；截图没有浏览器地址栏、真实账号、密码、私人账单或 EXIF 信息。测试中使用明确的无效模拟凭据。

公开历史也使用 Gitleaks 检查，持续集成对后续提交重复执行历史扫描。扫描和人工检查针对本次公开内容，不表示能自动识别未来加入的所有敏感数据。贡献者仍需复核自己的提交。

Kaggle 统计基于官方固定版本的 48,895 行、16 列原文件重新计算，共 49 张图；原 CSV 不随代码分发。Agent 文字来自先前生成的真实模型输出，在本地离线重放，页面及案例文档均明确说明。本次截图没有发起模型调用，也没有产生模型费用。演示账本重新初始化，不能据此推断任何部署的真实账单。
