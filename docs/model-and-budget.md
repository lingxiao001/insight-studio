# 模型配置与费用控制

模型解释是可选功能。未配置共享后端密钥时，统计、图表、历史和导出均可运行。当前实现面向 OpenRouter API，使用服务端指定模型与单一提供商端点，不做自动推理重试。

## 配置

| 变量 | 用途 |
| --- | --- |
| `LLM_API_KEY` | 共享服务端 OpenRouter 密钥，可留空 |
| `LLM_BASE_URL` | 当前支持 `https://openrouter.ai/api/v1` |
| `LLM_MODEL` | 模型目录 ID |
| `LLM_PROVIDER_ONLY` | 唯一允许的提供商端点 |
| `LLM_INPUT_PER_MILLION_USD` | 每百万输入 tokens 单价上限 |
| `LLM_OUTPUT_PER_MILLION_USD` | 每百万输出 tokens 单价上限 |

`.env.example` 提供 `deepseek/deepseek-v4-pro-0813` 与 `sail-research/fp4` 的示例，输入/输出上限分别为 0.45/0.80 USD/百万 tokens。它们是配置示例和拒绝更高价格的上限，不是永久价格承诺或“全市场最低”结论。FP4 是量化端点，不能宣称与其他精度质量相同。部署者应先核对[OpenRouter 模型目录](https://openrouter.ai/models)及[提供商路由文档](https://openrouter.ai/docs/features/provider-routing)。

服务端只读核验密钥和端点目录，要求支持所需的结构化输出、token 上限与 reasoning 参数。请求设置提供商 allowlist、`allow_fallbacks:false`、`require_parameters:true`、`zdr:true` 及价格上限。无法核验、涨价或端点不符合隐私条件时停止该次模型调用，保留统计报告。ZDR 依赖提供商资格与账户设置，并不意味着发送内容自动匿名。

## 用户额度

普通账号终身应用额度固定为 1 USD，跨所有密钥周期累计。管理员没有应用内累计金额上限，接口返回 `unlimited:true`，金额上限和剩余为 null；仍保留单次输出上限、价格核验、供应商余额、异常账单与隐私保护。

每笔请求绑定用户 ID、任务和密钥周期。用户不能指定其他人的计费身份，普通用户不能授权更换密钥或重置额度。管理员更换密钥、重启服务、删除任务均不清除任何人的历史费用。一个普通用户耗尽不会锁住全局模型功能。

这层限制只管理本应用发起的调用，不修改 OpenRouter 后台预算或其他应用的使用。当前允许自主注册，无法保证同一自然人只创建一个账号；对外运营需要额外的注册控制。

## 费用预留

金额内部使用整数微美元，费用向上取整。提交推理前以如下保守上界估算：

```text
输入 token 上界 = 2 × UTF-8 字节数(序列化 messages) + 8192
输出 token 上界 = 3200
预留美元 = 输入上界 × 输入单价上限 / 1,000,000
         + 3200 × 输出单价上限 / 1,000,000
         + 0.01 安全余量
```

先检查用户状态，再只读核验外部配置，最后用 SQLite `BEGIN IMMEDIATE` 原子重查并预留，避免并发超额。普通用户按自身跨周期的已结算、进行中和待核实总额判断。用量界面显示的是预留后的可用余额，不能据余额大于零保证足够完成下一笔。

## 结算状态

| 情况 | 账本行为 | 是否自动再推理 |
| --- | --- | --- |
| 有效 `usage.cost` | 按实际成本向上取整结算，释放多余预留 | 否 |
| 内容截断或审查不通过，但成本可靠 | 仍结算费用，保留统计报告 | 否 |
| 超时、服务异常、成本缺失或无效 | 保留完整预留为待核实 | 否 |
| 明确且结构可核验的推理前拒绝 | 释放该笔预留并记录原因 | 否 |
| 账单超出保护边界或异常金额 | 对该账户保守锁定并记录错误 | 否 |

未知费用不会被当成零。重启恢复时未完成推理也保留不确定预留。token 只累计可靠提供商字段，不从文本长度猜测实际用量。

管理员可在“模型用量”中输入新密钥，经只读验证后创建新的共享凭据周期。存在进行中调用时拒绝更换，避免计费身份混淆；这不是额度充值。密钥写入私有目录（700）和文件（600），数据库只存随机文件引用及指纹，API 不返回已存密钥。

模型输入与输出审查见 [Agent 设计](agent-design.md)；字段契约见 [API](api-contract.md)。公开演示截图使用重置后的本地演示账本与离线报告重放，不应作为模型成本估算或真实供应商账单证据。
