# Contributing

Please open a focused issue or pull request describing the problem, the
resulting behavior and relevant validation. Keep changes reproducible and
include meaningful tests for authentication, data isolation, statistical
semantics or billing behavior that you change.

Run backend tests and the frontend build as documented in
[the development guide](docs/development.md). Use synthetic or publicly
licensed data with attribution. Never use production credentials or charge
a real model during automated tests.

Contributions are accepted under AGPL-3.0-only. Preserve third-party notices,
avoid adding dependencies with incompatible terms, and do not submit code
or data that you lack permission to distribute. Do not add personal paths,
private infrastructure settings, real account fixtures or internal logs.
