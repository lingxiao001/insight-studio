# React 前端

前端使用 React、TypeScript、Vite 和 Plotly，提供登录注册、上传、任务进度、数据探索、字段画像、Agent 过程、历史与模型用量页面。纸白背景、灰褐文字与低饱和强调色用于长时间阅读统计内容。

需要 Node.js 24。从 `frontend` 目录运行：

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

开发地址为 `http://localhost:5173`，`/api` 代理到 `127.0.0.1:8108`。后端启动方式见[开发指南](../docs/development.md)。生产构建：

```bash
npm run build
npm audit
```

构建产物位于 `dist/`，由 FastAPI 或反向代理部署配置提供。

## 交互约定

- 登录身份变化时清理任务、结果与用量状态；工作区按用户 ID 重建，避免上一账号的迟到响应覆盖新会话。
- 上传设置允许指定关注字段与分析目标。模型开关只有在配置可用且用量读取成功、未锁定时才可启用；新任务界面会清楚展示选择。
- 上传和任务提交在途时锁定整个设置区及关闭入口，阻止重复提交。
- 保存报告的打开、过滤、翻页、专题切换和下载不调用模型。升级或失败重试先显示选择弹窗，默认免费统计，并显式发送 `use_llm:false`；用户主动选择后才允许模型调用。
- 普通账号展示 1 USD 终身额度；管理员用量上限和剩余为 `null`，显示“不设应用内累计额度上限”，不能把 `null` 当成零。用量失败时标记旧值而非伪造零费用。
- 只有管理员显示密钥配置入口。密钥输入不预填，服务端不回传已存密钥。
- v2 图表依据专题引用分类，同一图可以被多个专题引用，总数按唯一图 ID 计算；最多挂载六张图。旧报告缺少 `eda` 时按已有图表保守展示，不自动重新分析。
- 模型解释未被采用时展示统计报告提示，并提供 Agent 过程入口；提示本身不触发重试，也不推定一定产生费用。

弹窗支持焦点约束、Escape 与关闭后焦点恢复，打开时背景 inert；标签页使用方向键、Home/End 和 roving tabindex。进度使用可访问状态说明，减少动态效果设置会关闭非必要滚动动画。

公开仓库的截图使用新的本地演示实例。真实 Kaggle 统计与离线重放的模型文字分别注明，未复用私人服务截图。见[设计说明](../docs/design-system.md)、[案例来源](../docs/real-data-provenance.md)和[验证方法](../docs/testing.md)。
